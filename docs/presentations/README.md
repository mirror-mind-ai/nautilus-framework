# Presentations

This directory stores durable source material for Nautilus Agentic Framework presentations.

## Current decks

- [`nautilus-method-intro/slides.md`](nautilus-method-intro/slides.md): introductory deck for presenting the framework to other people.
- [`nautilus-method-intro/facilitator-notes.md`](nautilus-method-intro/facilitator-notes.md): narrative support, pacing, and adaptation notes for the introductory deck.

## Family context

The Nautilus Family has three bodies: the Nautilus Agentic Framework, the conceptual and pedagogical body; Nautilus App, the practical application experience delivered as Nautilus for Mirror; and the Nautilus Agentic Protocol, the formal and portable declaration of the grammar.

## Maintenance convention

Slides are source artifacts of the journey, not disposable prototypes. When the framework vocabulary evolves, update the deck and notes together so public explanation stays aligned with the framework documents in `docs/method/`.
