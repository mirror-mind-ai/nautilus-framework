# Presentations

Este diretório guarda material-fonte durável das apresentações do Nautilus Agentic Framework.

## Current decks

- [`nautilus-method-intro/slides.md`](nautilus-method-intro/slides.md): apresentação introdutória do framework para outras pessoas.
- [`nautilus-method-intro/facilitator-notes.md`](nautilus-method-intro/facilitator-notes.md): apoio narrativo, ritmo e notas de adaptação para a apresentação introdutória.

## Contexto da família

A família Nautilus possui três corpos: o Nautilus Agentic Framework, corpo conceitual e pedagógico; o Nautilus App, experiência prática de aplicação entregue como Nautilus for Mirror; e o Nautilus Agentic Protocol, declaração formal e portável da gramática.

## Convenção de manutenção

Os slides são artefatos-fonte da jornada, não protótipos descartáveis. Quando o vocabulário do framework evolui, atualize a apresentação e as notas em conjunto para que a explicação pública permaneça alinhada aos documentos do framework em `docs/method/`.
